### 2. ✅ Создан сервис переводчика

**Файл:** `services/translator.py` (НОВЫЙ)

**Функционал:**
- Класс `NewsTranslator`
- Метод `detect_language()` - определение языка
- Метод `translate_text()` - перевод текста
- Метод `translate_news()` - перевод новости (title + summary)

**Особенности:**
- Автоопределение языка
- Пропуск перевода если уже на русском
- Обработка ошибок
- Логирование

---

### 3. ✅ Интегрирован в процесс публикации

**Файл:** `main.py`, строки 222-260

**Новая логика:**

1. **Шаг 1: Перевод через Google Translate** (быстро, дешево)
   - Переводит английские новости на русский
   - Пропускает если уже на русском

2. **Шаг 2: AI анализ** (только если нужен через Smart Filtering)
   - Только для получения sentiment, coin, importance
   - НЕ для перевода (перевод уже сделан)
   - Использует `analyze_text` вместо `translate_and_analyze`

**Результат:**
- Экономия AI токенов (перевод делается бесплатно)
- Быстрее (Google Translate быстрее AI)
- Дешевле (экономия на AI API)

## 📊 Преимущества

### До:
- **AI перевод:** Дорого, медленно, избыточно

### После:
- **Google Translate:** Бесплатно, быстро, специализированно
- **AI анализ:** Только для sentiment/coin/importance (меньше токенов)

---

## 💡 Как это работает

```
1. Новость поступает на публикацию
2. Проверка: нужен ли перевод?
   - Если английская → Google Translate (быстро, бесплатно)
   - Если русская → пропуск перевода
3. Проверка: нужен ли AI анализ? (Smart Filtering)
   - Если да → AI анализ (sentiment, coin, importance)
   - Если нет → публикация с переведенным текстом
```
