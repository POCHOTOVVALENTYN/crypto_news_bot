### Для Userbot (ОБЯЗАТЕЛЬНО):

#### ШАГ 1: Убедитесь что credentials есть в .env

```bash
TG_API_ID=12345678
TG_API_HASH=abcdef1234567890abcdef1234567890
SOURCE_CHANNELS=@WalterBloomberg,@RBCCrypto,@Defiscamcheck
```

#### ШАГ 2: Создайте сессию (один раз)

Выполните команду:

```bash
python -c "from services.telegram_listener import setup_userbot; import asyncio; asyncio.run(setup_userbot())"
```

**Что произойдет:**
1. Вас попросят ввести номер телефона (формат: +380635609097)
2. Вам придет код в Telegram
3. Введите код
4. Если есть 2FA - введите пароль
5. Вы получите строку `TG_SESSION_STRING`

#### ШАГ 3: Скопируйте TG_SESSION_STRING

Из вывода команды найдите строку вида:
```
TG_SESSION_STRING=1BVtsOHwBu5Q7vabcdefghijklmnopqrstuvwxyz...
```

**ВАЖНО:** Скопируйте ВСЮ строку, включая `TG_SESSION_STRING=`

#### ШАГ 4: Добавьте в .env

Откройте файл `.env` и добавьте/обновите строку:

```bash
TG_SESSION_STRING=1BVtsOHwBu5Q7vabcdefghijklmnopqrstuvwxyz...
```

**Важно:**
- НЕ добавляйте кавычки
- НЕ добавляйте пробелы
- Скопируйте точно как есть

#### ШАГ 5: Удалите старый файл сессии (если есть)

```bash
rm anon_session.session
```

#### ШАГ 6: Перезапустите бота

```bash
python main.py
```

**Ожидаемый результат:**
- В логах: `✅ Использую StringSession из TG_SESSION_STRING`
- В логах: `✅ Userbot активен: @your_username`
- В логах: `🟢 Слушаю X каналов...`

## ⚠️ Возможные проблемы и решения

### Проблема 1: Gemini все еще возвращает 404

**Возможные причины:**
1. Модель `gemini-2.5-flash` недоступна в вашем регионе/аккаунте
2. API ключ не имеет доступа к этой модели
3. Нужна другая модель

**Решение:**
- Проверьте доступные модели в документации Google
- Или используйте OpenAI (fallback работает автоматически)
- Можно изменить модель в `services/ai_summary.py`, строка 42

---

### Проблема 2: Userbot все еще требует авторизацию

**Возможные причины:**
1. `TG_SESSION_STRING` не добавлен в `.env`
2. `TG_SESSION_STRING` скопирован неправильно (с пробелами, кавычками)
3. Сессия истекла или невалидна

**Решение:**
1. Проверьте что `TG_SESSION_STRING` есть в `.env`
2. Создайте новую сессию (ШАГ 2)
3. Обновите `TG_SESSION_STRING` в `.env`
4. Перезапустите бота

---

### Проблема 3: "Не удалось подключиться к каналу"

**Возможные причины:**
1. Вы не подписаны на канал
2. Неправильное имя канала

**Решение:**
1. Убедитесь что вы подписаны на канал в Telegram
2. Проверьте правильность имени (с @ или без)
3. Попробуйте использовать username канала
