# 🧠 Настройка AI Провайдеров: Hugging Face и Ollama

Этот документ описывает, как подключить бесплатные и локальные нейросети к вашему боту.

---

## 1. Hugging Face (Бесплатно)

Используем **Inference API** — это бесплатный доступ к мощным моделям вроде Llama 3 или Mixtral через сервера Hugging Face.

### Шаг 1: Получение ключа
1. Зарегистрируйтесь на [Hugging Face](https://huggingface.co/join).
2. Перейдите в настройки токенов: [Settings -> Access Tokens](https://huggingface.co/settings/tokens).
3. Нажмите **"Create new token"**.
4. Тип токена: **Type: Read** (достаточно прав на чтение).
5. Скопируйте токен (начинается с `hf_...`).

### Шаг 2: Настройка бота
1. Откройте файл `.env`.
2. Добавьте или найдите строку:
   ```env
   HUGGINGFACE_API_KEY=hf_ВашТокенЗдесь
   ```
3. Сохраните файл.
4. Перезапустите бота.

**Что под капотом?**
Бот настроен использовать модель `meta-llama/Meta-Llama-3-8B-Instruct`. Это быстрая и умная модель. Если серверам HF будет тяжело ("Model is loading"), бот это поймет и попробует другой провайдер.

## 2. Ollama (Локально, Бесплатно, Приватно)

Ollama позволяет запускать нейросети прямиком на вашем компьютере. Это идеальный вариант, если у вас есть видеокарта или мощный процессор (Mac M1/M2/M3).

### Шаг 1: Установка Ollama
1. Скачайте установщик с официального сайта: [ollama.com](https://ollama.com).
2. Установите и запустите приложение.
3. Откройте терминал и проверьте работу:
   ```bash
   ollama --version
   ```

### Шаг 2: Скачивание модели (Llama 3)
В терминале выполните команду для скачивания модели (весит около 4.7 ГБ):
```bash
ollama pull llama3
```
*Альтернатива для слабых ПК:* `ollama pull gemma:2b` (быстрее, но глупее).

### Шаг 3: Настройка бота
1. Убедитесь, что Ollama запущена (обычно висит иконка в трее или доступна по `http://localhost:11434`).
2. Откройте файл `.env` вашего бота.
3. Добавьте настройки:
   ```env
   OLLAMA_BASE_URL=http://localhost:11434
   OLLAMA_MODEL=llama3
   ```
   *Если бот запускается в Docker, укажите `http://host.docker.internal:11434` вмеcто localhost.*

4. Перезапустите бота.

## 🏗 Как работает выбор AI?

Бот использует систему каскада ("Лесенка надежности"). Он пробует сервисы в таком порядке:

1. **Gemini** (Google) — Быстро, бесплатно, умно. *Часто заканчиваются лимиты.*
2. **DeepSeek** — Очень дешево и умно.
3. **OpenAI** (GPT-4) — Надежно, но платно.
4. **Hugging Face** — Бесплатно, но может быть очередь.
5. **Ollama** — Локально. Работает всегда, пока включен ваш ПК.
6. **Simple Digest** — Если вообще ничего не работает (просто собирает заголовки).

Теперь ваш бот почти неуязвим для сбоев API! 🚀
