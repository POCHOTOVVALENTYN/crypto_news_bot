# ✅ Исправление конфликта зависимостей

## Проблема

**Конфликт зависимостей:**
- `googletrans==4.0.0rc1` требует `httpx==0.13.3` (старая версия)
- `google-genai 1.56.0` требует `httpx>=0.28.1,<1.0.0`
- `openai 1.40.0` требует `httpx>=0.23.0,<1`

**Также:**
- `google-genai 1.56.0` требует `pydantic>=2.9.0,<3.0.0`
- Была установлена `pydantic 2.5.3`

---

## ✅ Решение

### 1. Замена googletrans на deep-translator

**Файл:** `requirements.txt`

**Было:**
```txt
googletrans==4.0.0rc1
```

**Стало:**
```txt
deep-translator>=1.11.0
```

**Причины:**
- Современная библиотека
- Не конфликтует с httpx
- Поддерживает Google Translate
- Активно поддерживается

---

### 2. Обновление pydantic

**Файл:** `requirements.txt`

**Было:**
```txt
pydantic==2.5.3
```

**Стало:**
```txt
pydantic>=2.9.0,<3.0.0
```

**Причина:** Соответствие требованиям google-genai

---

### 3. Обновление translator.py

**Файл:** `services/translator.py`

**Изменения:**
- Заменен импорт `googletrans` на `deep_translator`
- Обновлена логика инициализации
- Обновлены методы перевода

**API совместимость:**
- Методы остались те же
- Интерфейс не изменился
- Код интеграции не требует изменений

---

## 📋 Инструкция по установке

```bash
# 1. Удалить старую библиотеку
pip uninstall googletrans -y

# 2. Установить новые зависимости
pip install -r requirements.txt

# Или установить вручную:
pip install deep-translator>=1.11.0
pip install "pydantic>=2.9.0,<3.0.0"
```
