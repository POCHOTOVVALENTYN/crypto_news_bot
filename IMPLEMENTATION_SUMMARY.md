## 1. ✅ Убран двойной вызов AI анализа

### Проблема:
- AI анализ вызывался дважды: при парсинге RSS и при публикации
- Это приводило к превышению квоты API (429 ошибки)

### Решение:
**Файл:** `main.py`, строки 166-183

**Было:**
```python
# AI анализ при парсинге RSS
if priority_quick >= 6:
    ai_analysis = await ai_analyzer.analyze_text(...)
priority = PriorityCalculator.calculate_priority(news, ai_analysis)
```

**Стало:**
```python
# Расчет приоритета БЕЗ AI (быстро, без запросов к API)
# AI анализ будет выполняться только при публикации для перевода и улучшения
priority = PriorityCalculator.calculate_priority(news, None)
```

**Результат:**
- ✅ AI анализ выполняется только один раз (при публикации)
- ✅ Снижение количества запросов к API примерно в 2 раза
- ✅ Меньше ошибок 429

## 2. ✅ Добавлен rate limiting для AI API

### Проблема:
- Слишком много одновременных запросов к AI API
- Нет задержек между запросами
- Превышение квоты

### Решение:
**Файл:** `services/ai_summary.py`

**Добавлено:**
1. Поля для rate limiting в `__init__`:
   ```python
   self._last_api_call_time = 0
   self._min_delay_seconds = 1.5  # Задержка 1.5 секунды между запросами
   ```

2. Метод `_rate_limit_wait()`:
   ```python
   async def _rate_limit_wait(self):
       """Ожидание для соблюдения rate limiting"""
       # Проверяет время с последнего запроса
       # Если прошло меньше min_delay_seconds - ждет
   ```

3. Вызов перед каждым AI запросом:
   - В `analyze_text()` - перед Gemini запросом
   - В `_analyze_with_openai()` - перед OpenAI запросом

**Результат:**
- ✅ Минимальная задержка 1.5 секунды между запросами
- ✅ Защита от превышения rate limits
- ✅ Более стабильная работа API

## 📝 Дополнительные замечания

### Rate limiting:
- Текущая задержка: 1.5 секунды между запросами
- Можно увеличить если все еще будут ошибки 429
- Можно сделать настраиваемой через config

### Свежесть новостей:
- Проверяется только дата (без времени)
- Если новость опубликована 23:59, а парсинг в 00:01 - пропустится
- Это приемлемо для большинства случаев
- Можно улучшить, учитывая часовой пояс
