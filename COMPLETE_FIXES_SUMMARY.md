## 📋 Новые изменения (исправление функции "Свежести")

### 3. ✅ Исправлена функция "Свежести" новостей

**Проблема из логов:**
```
📥 RSS: найдено 83, добавлено 0, отфильтровано 40
```

**Причина:**
- Функция `is_today_news()` была слишком строгой
- Проверяла только что новость опубликована "сегодня"
- Все новости отфильтровывались

**Решение:**
**Файл:** `utils/news_validator.py`

**Изменения:**
1. ✅ Изменена логика с "только сегодня" на "не старше 24 часов"
2. ✅ Улучшены форматы дат (добавлены форматы из feedparser)
3. ✅ Добавлена поддержка `time.struct_time` (если feedparser вернет его)
4. ✅ Добавлена поддержка `datetime` объектов
5. ✅ Улучшено логирование (показывает возраст новости)
6. ✅ Добавлен параметр `max_age_hours` (по умолчанию 24 часа)

**Было:**
```python
# Сравниваем только дату (без времени)
is_today = pub_date_only == today
```

**Стало:**
```python
# Проверяем возраст новости
age = now - pub_date_no_tz
is_fresh = age <= timedelta(hours=max_age_hours)  # По умолчанию 24 часа
```

**Результат:**
- ✅ Новости не старше 24 часов проходят проверку
- ✅ Более гибкая логика для RSS источников
- ✅ Улучшенное логирование для диагностики
- ✅ Поддержка различных форматов дат

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

### 429 ошибки:

**Статус:** Все еще могут быть, но это ожидаемо:
- Rate limiting работает (задержка 1.5 сек)
- Но квота уже превышена → нужно время для восстановления (часы)
- Rate limiting поможет предотвратить новые превышения

**Рекомендации:**
- Подождать несколько часов для восстановления квоты Gemini/OpenAI
- При необходимости можно увеличить задержку до 3-5 секунд

### Функция "Свежести":

**Текущая логика:** Не старше 24 часов (по умолчанию)

**Можно изменить:**
- Если нужно строже: уменьшить `max_age_hours` до 12-18 часов
- Если нужно мягче: увеличить до 36-48 часов
- Или изменить при вызове: `is_today_news(news, max_age_hours=12)`
