# 📊 Детальный анализ UX и структуры публикаций

## 🔍 Анализ текущей ситуации

### 1. Проблема с содержимым публикаций

**Текущая реализация:**
- RSS парсер извлекает только `entry.get("summary", "")`
- `summary` часто содержит только краткое описание или даже только заголовок
- Нет извлечения полного текста статьи
- В базе данных сохраняется только `summary` (без полного текста)

**Последствия:**
- ❌ Часто публикуется только заголовок
- ❌ Пользователи не получают достаточно информации
- ❌ Невозможно создать качественную выжимку без полного текста

### Проблемы UX:

1. **Недостаточно информации:**
   - Часто только заголовок
   - Нет выжимки/резюме статьи
   - Пользователь не понимает суть новости

2. **Визуальная перегруженность:**
   - Много эмодзи и метрик
   - Длинный футер (цены, индекс страха, технический анализ)
   - Может отвлекать от основного контента

3. **Структура:**
   - Заголовок в одном месте
   - Контент в другом
   - Футер слишком длинный

4. **Ограничения Telegram:**
   - Максимум 1024 символа для caption
   - Текущий код учитывает это, но не оптимально

**Вариант B: RSS Content Extension**

Некоторые RSS фиды содержат полный текст в `<content:encoded>` или `<description>`:
```python
# В RSS парсере
content = entry.get("content", [{}])[0].get("value", "")
if not content:
    content = entry.get("description", "")
```

**Преимущества:**
- ✅ Быстро (уже в RSS)
- ✅ Не требует дополнительных запросов

**Недостатки:**
- ❌ Не все RSS фиды содержат полный текст
- ❌ Часто только HTML превью

**Вариант C: Комбинированный подход (ЛУЧШЕЕ РЕШЕНИЕ)**

1. Попытка извлечь из RSS (`content:encoded`, `description`)
2. Если недостаточно - парсинг HTML статьи
3. Если не удалось - использовать summary

### Проблема 2: Копирайтер-выжимка (уменьшение токенов для ИИ)

**Идея:** Создать легковесную функцию, которая извлекает ключевые моменты из статьи БЕЗ использования ИИ.

**Методы:**

1. **Extractive Summarization (РЕКОМЕНДУЕТСЯ)**
   - Выбирает наиболее важные предложения из текста
   - Использует TF-IDF или TextRank алгоритмы
   - Библиотеки: `sumy`, `gensim`

2. **Keyword Extraction**
   - Извлекает ключевые слова и фразы
   - Формирует краткую выжимку на их основе

3. **Rule-based Summarization**
   - Удаляет вводные фразы
   - Оставляет предложения с числами, датами, именами
   - Сохраняет первое и последнее предложения

**Реализация (sumy):**
```python
from sumy.parsers.plaintext import PlaintextParser
from sumy.nlp.tokenizers import Tokenizer
from sumy.summarizers.text_rank import TextRankSummarizer

def create_extractive_summary(text: str, sentences_count: int = 3) -> str:
    """Создает выжимку из текста (без ИИ)"""
    try:
        parser = PlaintextParser.from_string(text, Tokenizer("russian"))
        summarizer = TextRankSummarizer()
        summary = summarizer(parser.document, sentences_count)
        return " ".join([str(sentence) for sentence in summary])
    except Exception:
        return text[:500]  # Fallback
```

**Преимущества:**
- ✅ Не требует ИИ API
- ✅ Быстро
- ✅ Экономит токены (можно отправлять в ИИ только выжимку)

**Использование:**
```python
# В check_queue_and_post
full_text = await get_article_content(news_item)
if len(full_text) > 1000:
    # Создаем выжимку (3-5 предложений)
    summary = create_extractive_summary(full_text, sentences_count=5)
    # Отправляем выжимку в ИИ (меньше токенов!)
    ai_data = await ai_analyzer.analyze_text(summary)
else:
    # Короткий текст - отправляем как есть
    ai_data = await ai_analyzer.analyze_text(full_text)
```
