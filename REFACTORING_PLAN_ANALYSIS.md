## ✅ РЕКОМЕНДАЦИИ ПО ПЛАНУ

### 1. Smart Filtering (ВЫСОКИЙ ПРИОРИТЕТ)

**Идея:** Проверять нужен ли AI перед вызовом

**Критерии для "AI не нужен":**
- Новость короткая (< 300 символов) И источник русский
- Новость содержит только ценовую информацию (regex паттерн)
- Новость уже на русском языке

**Реализация:** Добавить метод `needs_ai_processing()` в PriorityCalculator или создать отдельный класс

---

### 2. TradingView интеграция (ВЫСОКИЙ ПРИОРИТЕТ)

**Идея:** Добавить технический анализ в посты

**Библиотека:** `tradingview-ta` (python)

**Реализация:**
- Создать `services/technical_analysis.py`
- Получать RSI, MACD, Rating для монет
- Добавлять в футер поста

**Важно:** Не использовать AI для этого! Просто данные + шаблон

---

### 3. Content Hash для дедупликации (СРЕДНИЙ ПРИОРИТЕТ)

**Идея:** Добавить поле `content_hash` в БД

**Реализация:**
- Добавить колонку в таблицу news
- Вычислять hash при добавлении
- Использовать для быстрой дедупликации

---

### 4. Template Processing (СРЕДНИЙ ПРИОРИТЕТ)

**Идея:** Шаблоны для простых новостей без AI

**Примеры:**
- "💰 {coin} цена: ${price} ({change}%)"
- "📊 {coin} технический анализ: {rating}"

**Реализация:** Создать класс MessageTemplates

---

### 5. Batch Processing (НИЗКИЙ ПРИОРИТЕТ)

**Идея:** Дайджесты для мелких новостей

**Статус:** Сложно реализовать, можно оставить на будущее
