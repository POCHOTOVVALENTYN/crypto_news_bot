## 📝 ДЕТАЛЬНЫЙ ПЛАН

### ФАЗА 1: Smart Filtering

#### 1.1. Добавить needs_ai_processing() в PriorityCalculator

**Метод должен проверять:**
- Длина новости (< 300 символов + русский язык = не нужен AI)
- Тип новости (price action = не нужен AI)
- Язык новости (уже на русском = возможно не нужен перевод)

**Возвращает:** `bool` - нужен ли AI

---

#### 1.2. Использовать в check_queue_and_post

**Логика:**
```python
needs_ai = PriorityCalculator.needs_ai_processing(news_item)

if needs_ai:
    ai_result = await ai_analyzer.translate_and_analyze(...)
else:
    # Template processing
    ai_result = None  # Используем оригинал или шаблон
```

---

#### 1.3. Template Processing

**Для новостей без AI:**
- Используем оригинальный заголовок/текст
- Или простой шаблон если нужна минимальная обработка
