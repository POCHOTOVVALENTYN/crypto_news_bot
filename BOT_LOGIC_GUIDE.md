# 📖 Простой гайд по логике работы бота

## 🎯 Что делает бот в двух словах:

1. **Собирает новости** из RSS фидов и Telegram каналов
2. **Фильтрует и оценивает** важность новостей
3. **Публикует** важные новости в Telegram канал

## 🔢 Система приоритетов (детально)

### Как считается priority:

```
priority = 0  (начальное значение)

// 1. Ключевые слова (самый важный фактор)
if "hack" in текст:
    priority = max(priority, 10)
if "ETF approval" in текст:
    priority = max(priority, 9)
if "listing" in текст:
    priority = max(priority, 7)

// 2. Влиятельные персоны
if "Elon Musk" in текст:
    priority = max(priority, 6)

// 3. Премиум источники
if источник in [CoinDesk, Cointelegraph, ...]:
    priority = max(priority, 3)

// 4. Базовый приоритет
if priority == 0:
    priority = 1  // Минимум для всех валидных новостей

// 5. AI анализ (если был выполнен)
if AI вернул importance_score:
    priority = max(priority, AI_score)

// 6. Insider источники (максимальный приоритет)
if "Insider" in источник:
    priority = 10

return priority  // 0-10
```

### Что значит каждый priority:

- **10:** Критически важно (Insider, взломы) → публикация немедленно
- **9:** Очень важно (ETF, банкротства) → публикация в течение 5 минут
- **8:** Высокий (листинги, регуляция) → публикация в течение 15 минут
- **7:** Высокий (крупные транзакции) → публикация в обычной очереди
- **6:** Средний (значимые новости) → публикация в обычной очереди
- **3-5:** Средний (премиум источники) → публикация в обычной очереди
- **1:** Низкий (обычные новости) → публикация в обычной очереди
- **0:** Не релевантно → **НЕ СОХРАНЯЕТСЯ В БД**

## 🔑 Ключевые понятия

### Горячая новость (Hot News)
- Priority >= 6
- Публикуется **ВНЕ очереди** (игнорирует rate limiter)
- Обычно это: взломы, ETF, листинги, Insider новости

### Rate Limiter
- Ограничивает частоту публикаций
- Минимум 5 минут между постами (для обычных новостей)
- Горячие новости игнорируют это ограничение

### AI Analyzer
- Используется для:
  1. **Анализа важности** (при RSS парсинге для priority >= 6)
  2. **Перевода на русский** (при публикации)
  3. **Определения тональности** (Bullish/Bearish)
  4. **Определения монеты** (BTC/ETH/SOL)

### Декоратор @safe_task
- Защищает задачи от падения
- Ловит все исключения
- Отправляет алерты админу при ошибках
- Задача продолжает работать даже при ошибке

## ❓ Частые вопросы

### Q: Почему все новости отфильтрованы?
**A:** Возможно priority = 0 для всех новостей. Проверьте:
- Есть ли ключевые слова в новостях?
- Правильно ли работает PriorityCalculator?
- Проверьте логи на предмет ошибок

### Q: Почему новости не публикуются?
**A:** Проверьте:
- Rate limiter (прошло 5 минут?)
- Есть ли неопубликованные новости в БД?
- Работает ли Queue Poster?
- Проверьте логи на ошибки

### Q: Как работает Userbot?
**A:** 
- Подключается к Telegram как пользователь
- Слушает указанные каналы
- Все сообщения анализируются через AI
- Важные сохраняются с priority = 10

### Q: Что такое "вне очереди"?
**A:** 
- Горячие новости (priority >= 6) публикуются сразу
- Игнорируют rate limiter (5 минут)
- Обычные новости ждут своей очереди
