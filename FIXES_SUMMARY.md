## 📋 Что нужно сделать пользователю

### Для AI-анализа:

**НИЧЕГО!** Все исправления в коде. Если Gemini не работает, будет автоматический fallback на OpenAI.

**Если 404 ошибка сохраняется:**
- Возможно нужно проверить API ключ Gemini
- Или модель недоступна в вашем регионе
- Fallback на OpenAI должен работать

---

### Для Userbot:

**ШАГ 1: Создайте сессию**

Выполните команду:

```bash
python -c "from services.telegram_listener import setup_userbot; import asyncio; asyncio.run(setup_userbot())"
```

**ШАГ 2: Скопируйте TG_SESSION_STRING**

Из вывода команды скопируйте строку вида:
```
TG_SESSION_STRING=1BVtsOHwBu5Q7v...
```

**ШАГ 3: Добавьте в .env**

Откройте `.env` и добавьте/обновите:
```bash
TG_SESSION_STRING=1BVtsOHwBu5Q7v...
```

**ШАГ 4: Перезапустите бота**

```bash
python main.py
```

**Подробная инструкция:** См. `USERBOT_SETUP_GUIDE.md`
