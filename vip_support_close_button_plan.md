# План реализации: Кнопка "Завершить чат" в каждом сообщении

## 🎯 Цель
Добавить кнопку **"❌ Завершить чат"** под **каждым** сообщением в рамках сессии поддержки.
- **Для клиента**: Кнопка позволяет завершить диалог со своей стороны.
- **Для администратора**: Кнопка позволяет быстро закрыть сессию прямо из потока сообщений.

## ⚙️ Технический анализ
В текущей реализации для пересылки сообщений используется метод `bot.copy_message`.
Этот метод поддерживает параметр `reply_markup`. Мы будем использовать этот параметр, чтобы прикреплять Inline-клавиатуру с кнопкой закрытия к каждому пересылаемому сообщению.

### 1. Изменения в `RelayManager` (`services/relay_manager.py`)

Необходимо обновить методы `relay_to_admin` и `relay_to_user`.

*   **`relay_to_admin`**:
    *   При вызове `bot.copy_message` добавляем `reply_markup`.
    *   Кнопка: `InlineKeyboardButton(text="❌ Завершить", callback_data=f"relay_close_{session_id}")`.
    *   Это использует уже существующий механизм закрытия сессии администратором.

*   **`relay_to_user`**:
    *   При вызове `bot.copy_message` добавляем `reply_markup`.
    *   Кнопка: `InlineKeyboardButton(text="❌ Завершить", callback_data=f"user_close_{session_id}")`.
    *   Используем новый префикс `user_close_`, чтобы разделить логику (или создать отдельный хендлер для безопасности).

### 2. Изменения в Handlers (`handlers/premium_services.py`)

*   **Новый хендлер `user_close_session`**:
    *   Ловит callback `user_close_{session_id}`.
    *   Проверяет, что сессия активна и принадлежит этому пользователю.
    *   Вызывает `relay_manager.close_session`.
    *   Уведомляет пользователя: "Диалог завершен".
    *   Уведомляет администратора: "Пользователь завершил диалог".
    *   Убирает кнопки (опционально редактирует сообщение, чтобы убрать кнопку, но проще просто обработать нажатие).

*   **Обновление `admin_close_session`**:
    *   Существующий хендлер `relay_close_` уже работает. Проверим, нуждается ли он в доработке (например, уведомление пользователя). В текущем коде уведомление есть.

2.  **Модификация `handlers/premium_services.py`**:
    *   Добавить обработчик `user_close_session`.

3.  **Тестирование**:

    *   Проверка отправки сообщений от админа (кнопка у юзера).
    *   Нажатие кнопки юзером -> закрытие сессии.
    *   Нажатие кнопки админом -> закрытие сессии.
