# 🔍 Анализ логов и публикации на ошибки и баги

## 🐛 Выявленные проблемы

### Проблема 1: Ключевые моменты на английском языке (КРИТИЧНО)

**Симптом:**
```
📝 Ключевые моменты:
• Bitcoin bears might have the upper hand at the yearly open, but charts suggest bulls will fiercely defend these key pric...
```

**Причина:**
1. `full_content` извлекается на английском языке (из RSS/HTML)
2. Переводчик переводит только `title` и `text_for_ai` (выжимку), но НЕ переводит `full_content`
3. `key_points` извлекаются из непереведенного `full_content`
4. В публикации показываются ключевые моменты на английском

**Логи подтверждают:**
```
✅ Новость переведена с en на ru
⏭️ Smart Filtering: пропуск AI обработки для новости: Битва между биткоин-быками...
```

Заголовок переведен, но `full_content` остался на английском.

---

### Проблема 2: Все RSS новости отфильтрованы

**Логи:**
```
📥 RSS: найдено 89, добавлено 0 (0 высокоприоритетных), отфильтровано 49
(дубликаты: 40, старые: 49, валидация: 0, приоритет 0: 0)
```

**Анализ:**
- Найдено: 89
- Добавлено: 0 ❌
- Отфильтровано: 49 (но должно быть 89!)
- Дубликаты: 40
- Старые: 49
- Итого: 40 + 49 = 89 ✅ (совпадает)

**Проблема:** Все новости отфильтрованы как дубликаты или старые.

**Возможные причины:**
1. Извлечение `full_content` происходит ДО фильтрации (может быть медленно)
2. Новости действительно дубликаты или старые
3. Проблема с извлечением контента (таймауты, ошибки)

### Проблема 3: Ключевой момент обрезан

**Симптом:**
```
• Bitcoin bears might have the upper hand at the yearly open, but charts suggest bulls will fiercely defend these key pric...
```

**Причина:** Код обрезает каждый пункт до 120 символов:
```python
point_display = point_clean[:120] + "..." if len(point_clean) > 120 else point_clean
```

Но обрезка происходит посреди слова ("pric..." вместо "price levels").

## 🔧 Исправления

### Исправление 1: Перевод full_content

**Проблема:** `full_content` не переводится, поэтому `key_points` на английском.

**Решение:** Переводить `full_content` если он на английском языке, или переводить `key_points` после извлечения.

**Вариант A (РЕКОМЕНДУЕТСЯ):** Переводить `key_points` после извлечения:
```python
# Извлекаем ключевые моменты из full_content (может быть на английском)
key_points = ContentSummarizer.extract_key_points(full_content, points_count=3)

# Если новость была переведена, переводим key_points тоже
if translated_data and key_points:
    # Переводим каждый ключевой момент
    translated_points = []
    for point in key_points:
        try:
            translated_point = await translator.translate_text(point, target_lang='ru')
            if translated_point:
                translated_points.append(translated_point)
            else:
                translated_points.append(point)  # Fallback на оригинал
        except Exception:
            translated_points.append(point)
    key_points = translated_points
```

**Вариант B:** Переводить `full_content` перед извлечением key_points (но это дороже по токенам).

### Исправление 2: Улучшенная обрезка текста

**Проблема:** Обрезка происходит посреди слова.

**Решение:** Обрезать по последнему пробелу перед лимитом:
```python
def smart_truncate_words(text: str, max_chars: int) -> str:
    """Обрезает текст по словам (не режет слова)"""
    if len(text) <= max_chars:
        return text
    
    cut = text[:max_chars]
    last_space = cut.rfind(' ')
    
    if last_space > max_chars * 0.7:  # Если пробел не слишком близко к началу
        return cut[:last_space] + "..."
    
    return cut + "..."
```
