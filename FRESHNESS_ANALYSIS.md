# 🔍 Анализ функции "Свежести" новостей

## 📋 Требование

Публиковать только новости текущего дня, не предыдущего.

---

## 🔍 ТЕКУЩАЯ ЛОГИКА

### В NewsValidator.is_news_relevant:

```python
MAX_AGE_HOURS = 48  # Максимальный возраст новости в часах
```

**Логика:**
- Проверяет что новость не старше 48 часов
- Если новость старше 48 часов - отфильтровывается

**Проблема:**
- 48 часов = 2 дня
- Новости вчерашнего дня проходят проверку
- Нужно только новости СЕГОДНЯ

---

## 🔧 РЕШЕНИЕ

### Вариант 1: Проверка что новость сегодняшняя (РЕКОМЕНДУЕТСЯ)

**Логика:**
- Парсим дату публикации
- Сравниваем с сегодняшней датой
- Пропускаем только если дата = сегодня

**Плюсы:**
- Простая реализация
- Четкое требование: только сегодняшние новости

**Минусы:**
- Если новость опубликована 23:59, а парсинг в 00:01 следующего дня - пропустится
- Но это приемлемо для большинства случаев

---

### Вариант 2: Проверка что новость не старше N часов (текущий подход)

**Логика:**
- Проверяем возраст новости в часах
- Если > N часов - пропускаем

**Проблема:**
- Сейчас N = 48 часов (2 дня)
- Это слишком много для требования "только сегодня"

---

## 🎯 РЕКОМЕНДУЕМОЕ РЕШЕНИЕ

**Комбинация:**

1. **При парсинге RSS:** Проверка что новость сегодняшняя
   - Добавить метод `is_today_news(news_item)` в NewsValidator
   - Использовать в `scheduled_parsing` вместо `is_news_relevant`

2. **При публикации:** Можно использовать более мягкую проверку (например, не старше 24 часов)
   - На случай если новость была добавлена поздно вечером, а публикация на следующий день
